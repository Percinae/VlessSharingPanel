Только выбранные приложения

Список приложений задаётся на устройстве. VLESS-ссылка не переносит его, а VPS не видит названия мобильных приложений.

Android · v2rayNG

  1. Импортируйте профиль по ссылке или QR и откройте в v2rayNG настройки Per-app proxy («Прокси для приложений»).
  2. Включите Enable per-app. Оставьте Bypass Mode выключенным: в этом режиме отмеченные приложения используют VLESS.
  3. Отметьте WhatsApp, Telegram и Google Chrome. При необходимости добавьте другие приложения в этом же списке.
  4. Перезапустите VPN в v2rayNG и проверьте соединение отдельно в каждом выбранном приложении. Остальные приложения будут выходить напрямую через сеть телефона.

iPhone и iPad · Shadowrocket

Для обычной установки Shadowrocket точный список приложений не подтверждён. Правила по доменам и IP не равнозначны выбору приложений; особенно для Chrome, который открывает любые сайты. Не используйте их как гарантию «только WhatsApp, Telegram и Chrome».

Серверное разделение РФ/Нидерланды применяется к трафику, который действительно попал в VLESS. Подробности для Windows и ссылки на источники — в документации проекта.
